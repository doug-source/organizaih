# Sistema de gestão de clientes, produtos e estoque

## Sobre o sistema

Essa aplicação foi desenvolvida com o intuito de auxiliar no controle de clientes, estoque e vendas.

Atualmente possui os seguintes recursos:

-   Login
    -   usando as credenciais do Google
    -   utilizando senha (tradicional)
-   Esqueci minha senha
-   Registro de contas (préviamente autorizadas)
-   Manter-se logado
-   CRUD de:
    -   Clientes
    -   Categorias de produtos
    -   Produtos
    -   Estoque
    -   Vendas
-   Análise gráfica da quantidade de:
    -   Produtos mais vendidos
    -   Clientes que mais compram produtos
-   Idiomas
    -   Português (pt-BR)
    -   Inglês (en-US)
-   Temas
    -   Light
    -   Dark
